# App 对外错误代码

用户界面只显示简短说明和下列错误代码，不得直接显示原生异常、接口响应、堆栈或下载地址。完整诊断信息仅写入开发日志和匿名客户端错误上报。

| 错误代码 | 内部含义 |
| --- | --- |
| `UPD-CHECK-001` | 检查更新时网络不可用或超时 |
| `UPD-CHECK-002` | 更新检查服务异常 |
| `UPD-FETCH-001` | OTA 更新下载网络失败 |
| `UPD-FETCH-002` | OTA 更新资源下载失败 |
| `UPD-SIGN-001` | OTA 更新签名校验失败 |
| `UPD-RELOAD-001` | OTA 下载后重载失败 |
| `UPD-PKG-001` | APK 版本元数据无效 |
| `UPD-PKG-002` | APK 安装包下载失败 |
| `UPD-PKG-003` | APK 大小或摘要校验失败 |
| `UPD-INSTALL-001` | Android 安装权限或安装器不可用 |
| `UPD-UNKNOWN-999` | 未分类的更新异常 |

新增错误类型时，必须先在 `src/lib/app-error-codes.ts` 注册稳定代码，再在本表补充；已发布代码不得改变含义或复用于其他错误。
